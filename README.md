# Roblox 全功能查询插件（AstrBot 版）

Roblox 平台综合查询工具，支持**用户 / 游戏 / 群组 / 好友粉丝关注列表**一站式查询。
本插件由 NoneBot2 插件 [nonebot_plugin_roblox_search](https://github.com/maoyyds-cn/nonebot_plugin_roblox_search)（v1.3.5，作者 MrMao）迁移而来，全部查询功能与原插件一致，仅适配了 AstrBot 框架。

> 数据源与原插件一致，使用第三方代理 API（`*.rotunnel.com`）查询 Roblox 数据，并非 Roblox 官方接口。

## 安装

1. 将本插件目录重命名为 `astrbot_plugin_roblox_search`，放入 AstrBot 的 `data/plugins/` 目录下。
2. 在 AstrBot WebUI 中启用插件，等待依赖自动安装（`httpx` / `pillow` / `python-dateutil`）。
3. 在插件配置面板中按需配置后即可使用。

## 功能命令

| 命令 | 功能 |
|---|---|
| `/菜单`（别名 `/帮助` `/menu`） | 查看功能菜单（精美图片） |
| `/用户名搜索 [用户名]` | 根据用户名查询用户资料、头像、形象图、在线状态、群组、好友/粉丝/关注数 |
| `/用户ID搜索 [数字ID]` | 按用户ID查询用户完整资料 |
| `/群组名搜索 [群组名]` | 模糊搜索群组并展示详情 |
| `/群组ID搜索 [数字ID]` | 查询群组详情与职位列表 |
| `/游戏名搜索 [游戏名]` | 搜索游戏、在线人数、访问量、收藏数 |
| `/游戏ID搜索 [数字ID]` | 查询游戏详情与公开服务器列表 |
| `/获取好友列表 [用户ID]` | 读取用户前 10 位好友 |
| `/获取粉丝列表 [用户ID]` | 读取用户前 10 位粉丝 |
| `/获取关注列表 [用户ID]` | 读取用户前 10 位关注 |

示例：`/用户名搜索 Roblox`、`/游戏ID搜索 292439477`

## 配置说明

在 AstrBot WebUI 的插件配置面板中可设置：

- **`search_white_list`**（群白名单，默认 `[]`）
  - 留空：所有群均可使用全部查询功能；
  - 填写群号列表：仅白名单内的群可使用查询功能（菜单始终可用），未授权群会收到提示；**私聊不受限制**。
- **`allow_no_slash_command`**（无斜杠触发开关，默认 `true`）
  - 开启后，直接发送「用户名搜索 Roblox」（不带 `/`）也可触发命令；
  - 关闭后仅支持 `/` 斜杠命令，避免普通聊天误触发。

## 与 NoneBot 原版的差异

- **HTTP 库**：原版在异步中使用同步 `requests`（会阻塞事件循环），本版按 AstrBot 规范改用 `httpx.AsyncClient`，其余请求头、超时、重试、429 限流退避逻辑与原版一致。
- **图片发送**：原版直接发送图片字节流，本版统一为「下载/生成 → 临时文件 → 图片组件」，兼容更多平台。
- **白名单**：原版未配置白名单时**全部功能禁用**，本版改为留空即全开放（装即用）。
- **无斜杠触发**：原版固定支持，本版改为配置项可开关。

## 注意事项

- 依赖系统具备访问 `*.rotunnel.com` 的网络环境（与使用原插件时的要求一致）。
- 好友 / 粉丝 / 关注、在线状态等接口偶尔可能被限流（429），插件已内置自动重试与退避。
- 本项目仅供学习交流，请遵守 Roblox 与相关 API 的使用条款。
